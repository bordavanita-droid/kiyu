# Image library

Drop embroidery design photos here — JPG or PNG, under 4 MB, square or 4:5 portrait.
Files are picked up automatically in sorted filename order; no config change needed.

These are served publicly from `raw.githubusercontent.com` so Meta can fetch them, so
only add images you are happy to have publicly readable.

`elephant.png` is the seed image so day one has something real to post. Replace it once
you have your own design photos in here.
